# 🚀 Быстрый старт

## 1. Получите токен бота

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям (придумайте имя и username)
4. Скопируйте полученный токен

## 2. Узнайте свой Telegram ID

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте `/start`
3. Скопируйте ваш ID

## 3. Настройте бота

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env
nano .env  # или любым другим редактором
```

Вставьте в `.env`:
```bash
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
OWNER_ID=ваш_telegram_id
```

## 4. Запустите бота

```bash
# Активируйте виртуальное окружение
source venv/bin/activate

# Запустите
python run.py
```

## 5. Проверьте работу

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Отправьте `/help` - вы должны увидеть команды владельца

## 6. Создайте первый розыгрыш

1. Отправьте `/create_giveaway`
2. Следуйте инструкциям бота
3. После завершения увидите превью
4. Подтвердите создание

## Команды для владельца

```bash
/add_admin 123456789      # Добавить админа
/remove_admin 123456789   # Удалить админа
/list_admins              # Список админов
/create_giveaway          # Создать розыгрыш
```

## Остановка бота

Нажмите `Ctrl+C` в терминале

## Проблемы?

1. **Бот не запускается?**
   - Проверьте правильность токена в `.env`
   - Убедитесь что виртуальное окружение активировано

2. **Нет прав владельца?**
   - Проверьте OWNER_ID в `.env`
   - Перезапустите бота

3. **Ошибки БД?**
   - Запустите: `alembic upgrade head`
