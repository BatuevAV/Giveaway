### Структура проекта
```
Giveaway/
├── config/              # Конфигурация
│   └── __init__.py      # Настройки приложения (Settings)
├── src/                 # Исходный код
│   ├── __init__.py
│   ├── bot.py          # Основной класс бота GiveawayBot
│   ├── handlers.py     # Обработчики команд (заглушки)
│   ├── database.py     # Работа с БД (Database)
│   └── models.py       # SQLAlchemy модели (User, Giveaway, Participation)
├── tests/              # Тесты
│   ├── __init__.py
│   ├── conftest.py     # Фикстуры pytest
│   ├── test_bot.py     # Тесты бота
│   ├── test_database.py # Тесты БД
│   └── test_models.py  # Тесты моделей
├── .env.example        # Пример переменных окружения
├── .gitignore         # Игнорируемые файлы
├── pytest.ini         # Конфигурация pytest
├── README.md          # Документация
├── requirements.txt   # Зависимости Python
├── run.py            # Точка входа для запуска
└── setup.sh          # Скрипт установки
```

### Зависимости
- python-telegram-bot==20.7 - библиотека для работы с Telegram Bot API
- python-dotenv==1.0.0 - загрузка переменных окружения
- sqlalchemy==2.0.23 - ORM для работы с БД
- alembic==1.13.1 - миграции БД
- aiosqlite==0.19.0 - асинхронный драйвер SQLite
- greenlet==3.2.4 - поддержка asyncio в SQLAlchemy
- pytest==7.4.3 - фреймворк для тестирования
- pytest-asyncio==0.21.1 - поддержка async тестов
- pytest-cov==4.1.0 - покрытие кода тестами

### Реализованный функционал

#### Бот (src/bot.py)
- Класс `GiveawayBot` с базовой структурой
- Команды `/start` и `/help`
- Логирование
- Настройка обработчиков команд

#### База данных (src/database.py)
- Класс `Database` для работы с SQLite
- Асинхронные операции с БД
- Методы:
  - `init_db()` - инициализация БД
  - `create_user()` - создание пользователя
  - `get_user_by_telegram_id()` - получение пользователя
  - `get_or_create_user()` - получение или создание

#### Модели (src/models.py)
- `User` - пользователи бота
- `Giveaway` - розыгрыши
- `Participation` - участие в розыгрышах
- Связи между моделями

#### Конфигурация (config/__init__.py)
- Класс `Settings` для управления настройками
- Загрузка из переменных окружения
- Валидация настроек

## 🚀 Как использовать

### 1. Автоматическая установка
```bash
cd /Users/aleksandrbatuev/Documents/WORK/Giveaway
./setup.sh
```

### 2. Ручная установка
```bash
# Создать виртуальное окружение
python3 -m venv venv

# Активировать
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Создать .env файл
cp .env.example .env
# Отредактировать .env и добавить токен бота

# Запустить тесты
pytest
```

### 3. Запуск бота
```bash
source venv/bin/activate
python run.py
```
