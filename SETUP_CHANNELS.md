# Настройка каналов для анонсов

## Чтобы бот мог публиковать анонсы, выполните следующие шаги:

### 1. Добавьте бота в канал/группу

**Для канала:**
1. Откройте канал в Telegram
2. Нажмите на название канала → "Управление каналом"
3. Нажмите "Администраторы" → "Добавить администратора"
4. Найдите вашего бота по username
5. **ВАЖНО:** Включите права "Публикация сообщений"
6. Сохраните

**Для группы:**
1. Откройте группу в Telegram
2. Нажмите на название группы → "Управление группой"
3. Нажмите "Администраторы" → "Добавить администратора"
4. Найдите вашего бота по username
5. Включите необходимые права
6. Сохраните

### 2. Получите Chat ID

**Способ 1: Через бота @userinfobot**
1. Перешлите любое сообщение из канала/группы боту @userinfobot
2. Бот пришлет информацию, включая Chat ID
3. Для каналов ID начинается с `-100`, например: `-1001234567890`

**Способ 2: Через бота @getmyid_bot**
1. Добавьте @getmyid_bot в канал/группу
2. Отправьте команду `/my_id@getmyid_bot`
3. Бот ответит с Chat ID

**Способ 3: Вручную**
1. Зайдите в веб-версию Telegram (web.telegram.org)
2. Откройте канал/группу
3. Посмотрите URL: `web.telegram.org/k/#-1234567890`
4. Число после `#` и есть Chat ID (добавьте `-100` в начало для каналов)

### 3. Используйте Chat ID в боте

При создании розыгрыша на шаге "Целевые чаты":
- Введите Chat ID через запятую
- Например: `-1001234567890, -1009876543210`
- Или нажмите "Пропустить", если не нужны анонсы

### 4. Для обязательных каналов (проверка подписки)

На шаге "Обязательные каналы":
- Укажите Chat ID каналов через запятую
- Пользователи должны быть подписаны на эти каналы для участия
- Канал должен быть **публичным** или бот должен быть администратором

## Частые ошибки

❌ **"Bot was kicked from the channel"**
→ Добавьте бота обратно в канал как администратора

❌ **"Chat not found"**
→ Проверьте правильность Chat ID (должен начинаться с `-`)

❌ **"Bot is not a member of the channel"**
→ Добавьте бота в канал

❌ **"Bot doesn't have permission to post"**
→ Дайте боту права на публикацию сообщений

❌ **"User not found"**
→ Пользователь должен хотя бы раз общаться с ботом

## Пример правильных настроек

```
Целевые чаты (для анонсов):
-1001234567890, -1009876543210

Обязательные каналы (для проверки подписки):
-1001111111111, -1002222222222
```

## Тестирование

1. Создайте тестовый канал
2. Добавьте бота как администратора с правами на публикацию
3. Получите Chat ID
4. Создайте тестовый розыгрыш
5. Укажите Chat ID в целевых чатах
6. Опубликуйте розыгрыш
7. Проверьте что анонс появился в канале
